# olympic-games-data-analysis
Olympic Games data analysis using Python and Pandas
Dataset: The dataset was obtained from Kaggle. The source link is provided for reference. 
Olympic Games Data Analysis

📌 Project Overview

This project analyzes historical Olympic Games data to identify patterns and trends related to athletes, countries, sports, events, and medal distribution.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

📊 Analysis Performed

- Analyzed athlete participation across Olympic years
- Studied medal distribution across countries
- Analyzed different sports and events
- Examined participation by gender
- Identified trends and patterns in Olympic data
- Created visualizations to present the findings

📂 Dataset

The project uses a historical Olympic Games dataset. The dataset contains information about athletes, countries, sports, events, years, seasons, and medals.

🔍 Key Skills Demonstrated

- Data cleaning
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data filtering and grouping
- Data visualization
- Working with Pandas DataFrames
